# Financial Time — Terminal V2
Aplicação web estática para iPad em horizontal. Publicar no GitHub Pages carregando os 7 ficheiros **na raiz** do repositório `financial-time`.

## Atenção
Os preços, gráficos e nomes das empresas são **fictícios** e não devem ser usados para decisões de investimento. Os relógios são reais; o estado das bolsas fica indisponível até existir integração com calendários de negociação.

## Alterações V2
Fundo preto, tipografia editorial inspirada em jornais financeiros (sem usar fontes proprietárias), data por extenso, Lisboa ao centro dos relógios, gráficos verdes/vermelhos, gráficos mais próximos das cotações, espaço reservado à direita, cartões inferiores mais sóbrios e premium.

## Publicação
No GitHub, substituir `index.html`, `style.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg` e `README.md` na raiz do repositório. O GitHub Pages publica automaticamente após o commit. Se o iPad mostrar uma versão antiga, fechar e reabrir a app, ou atualizar no Safari.
